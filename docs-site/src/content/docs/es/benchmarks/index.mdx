Estos son **instantáneas estáticas** de tablas de clasificación públicas, actualizadas manualmente — no están activas Medición OpenCodex. Cada panel enumera su fuente, fecha de captura y nota de licencia. Las clasificaciones de puntuación por dólar solo aparecen en los panels donde cada fila lleva una Costo por tarea.

Los panels se agrupan por dominio de tarea:

- [Codificación](./coding/) — DeepSWE, Agente de codificación AA, FrontierCode, FrontierSWE, Banco de programa, Maratón SWE
- [Frontend](./frontend/) — Frontend Code Arena
- [Terminal](./terminal/) — Terminal Bench 2.1
- [Seguridad](./security/) — Cybench
- [Inteligencia](./intelligence/) — índice de inteligencia AA
